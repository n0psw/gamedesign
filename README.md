# SWARM SURVIVOR

2D minimalist arena survival roguelite (Brotato / Vampire Survivors-like) с упором на **стихийные цепные реакции** и **100% прозрачную математику статов**. TypeScript + Canvas 2D, без внешних ассетов — вся графика это квадрат, треугольники и свечение.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # продакшн-сборка в dist/ (можно выложить как статический сайт)
```

**Управление:** WASD / стрелки — движение (прицеливание и стрельба автоматические) · `Esc` пауза + статы · `1/2/3` выбор карточки · `Enter` старт волны · `R` реролл · `M` звук · `N` цифры урона · `F` фуллскрин. Всё остальное — мышью.

## Что внутри игры

- **10 волн** по 20–60 с, на 10-й — босс **Sentinel** (радиальные залпы, призыв роя, 2 фазы). Победа = убить босса.
- **4 персонажа:** Vanguard (просто), Pyromancer (масло + огонь), Stormcaller (вода + электричество), Cryomancer (лёд + удар, сложный).
- **8 видов оружия** (Pulse, Fireball, Oil Trail, Hydro Burst, Arc Emitter, Frost Shard, Orbital Blades, Shock Nova), до 6 слотов; **слияние** двух одинаковых оружий одного тира → тир выше (до T4).
- **6 типов врагов** (все — красные треугольники): drone, swarmer, brute, dasher (рывок с телеграфом), shooter, boss; плюс «кольцо роя» в середине волны.
- **Level-up:** XP-кристаллы → пауза → 3 карточки (4 редкости, карты с компромиссами). **Магазин** между волнами: предметы (≈25 шт. с редкостями), оружие, реролл, слияние.
- **13 реакций** (кодекс — в главном меню):

| Триггер | Реакция |
|---|---|
| Oiled + Fire | INFERNO (AoE + Burning) |
| Oiled + Electric | OVERLOAD (AoE + Stun) |
| Wet + Electric | CONDUCTION (цепь по мокрым) |
| Wet + Fire | STEAM BURST |
| Wet + Ice | FLASH FREEZE (заморозка мокрых рядом) |
| Chilled + Ice | DEEP FREEZE |
| Burning + Ice | THERMAL SHOCK |
| Frozen + Kinetic | SHATTER |
| Лужа масла + Fire | OIL BLAST (**цепная реакция по соседним лужам**) |
| Лужа масла + Electric | OIL SHOCK |
| Лужа воды + Electric / Ice / Fire | POND SHOCK / POND FREEZE / POND STEAM |

Горящий враг, зашедший в масло, тоже поджигает его; любой взрыв поджигает лужи в радиусе — отсюда цепочки.

## Прозрачная математика

Итог любого стата = `(base + Σ add) × (1 + Σ pct / 100)`. Описания генерируются из данных строго в формате `+15% Fire Damage`, `-5% Movement Speed`, `+20 Max HP`. В магазине и на паузе **наведите на стат** — увидите разбивку по источникам. Описания оружия считаются из *текущих* статов (реальный урон, кулдаун, радиус).

Урон оружия = `base × tier(1/1.6/2.4/3.5) × (1+Damage%) × (1+Element%) × crit`.
Урон реакции = `base × (1+Damage%) × (1+Element%) × (1+Reaction Damage%)`, радиус × `(1+AOE%)`, длительности × `(1+Effect Duration%)`.

## Архитектура (`src/`)

| Файл | Роль |
|---|---|
| `stats.ts` | статы, модификаторы, форматирование, разбивка |
| `data.ts`, `reactions.ts` | **все данные**: оружие, враги, карточки, предметы, персонажи, таблица реакций |
| `sim.ts` | симуляция боя без DOM (враги, снаряды, статусы, лужи, реакции) |
| `director.ts` | спавн волн, босс, кольцо роя |
| `run.ts` | прогрессия: XP, карточки, магазин, слияние, фазы |
| `render.ts`, `ui.ts`, `fx.ts` | отрисовка (батчинг для сотен врагов), экраны, частицы |
| `game.ts`, `main.ts`, `input.ts`, `audio.ts` | сцены, цикл (фикс. шаг 60 Гц), ввод, синтез звука |
| `bot.ts` | бот для тестов и баланса |

Новая реакция / предмет / карточка — **одна запись в данных**, код не трогается.

## Тесты и баланс

```bash
npm test                 # 115 тестов: статы, данные, все реакции, цепи луж, оружие, ИИ врагов, босс, директор волн, экономика, поток забега, фаззинг, перфоманс
npm run balance 12 smart # симуляция N забегов ботом по каждому персонажу
npm run e2e              # реальный Chrome (headless): меню, бой, level-up, магазин, пауза, стресс 340 врагов + скриншоты
npm run e2e:ui           # UI-механики в Chrome: выбор персонажа, пауза, слияние, реролл, покупка, retry, рекорды
npm run e2e:run          # полный забег бота в браузере через реальный рендер
```
(e2e требует запущенный `npm run dev` и установленный Google Chrome.)

Результаты баланс-симуляции (умный бот, 12 забегов): Vanguard 2/12 побед, Pyromancer 6/12, Stormcaller 6/12, Cryomancer 2/12 — Easy персонаж слабее синергийных, потому что не имеет встроенных комбо; Cryo — самый технический.

## Идеи на потом
Мета-прогрессия между забегами, бесконечный режим после босса, больше оружия/реакций (газ, кислота), настройки сложности, мобильное управление.
